# 서울 학교 공간 지도

서울 학교 1,368곳(학교알리미 2026 공시, 국립·공립·사립)의 **공간** — 시설 개방, 학생·학급 수, 학생 수 추이, 학교 부지(교지) 면적 — 을 지도와 목록으로 함께 보는 화면입니다.

- 화면: GitLab Pages 주소(이 저장소의 [배포 > Pages])에서 엽니다.
- 쓰는 법과 화면 읽는 법: [`서울학교공간지도/활용_안내.md`](서울학교공간지도/활용_안내.md)
- 자료별 출처·기준일: [`서울학교공간지도/데이터_출처_기준.md`](서울학교공간지도/데이터_출처_기준.md)

## 원칙
- 값과 비교 기준(같은 구·같은 학교급, 서울 전체, 전년)만 보여 주고 "과밀·유휴·우선순위" 같은 판정은 하지 않습니다.
- **공시값은 실제 이용 가능 여부와 다를 수 있습니다.** 이용 조건·절차는 학교 카드의 연락처로 학교에 확인해 주세요.

## 구성
| 경로 | 내용 |
|---|---|
| `서울학교공간지도/서울학교공간지도.html` | 화면 전체(한 파일). Pages에서는 `index.html` |
| `서울학교공간지도/data/*.js` | 화면이 읽는 자료 스냅샷(학교알리미 공시, NEIS 학교기본정보, 전국초중등학교위치표준데이터 등 공공데이터) |
| `.gitlab-ci.yml` | Pages 배포 설정 |

외부 API를 부르지 않고 저장된 자료만 읽습니다(카카오 지도 SDK만 예외). 화면 안의 카카오 지도 키는 웹용 JavaScript 키로, 등록된 도메인에서만 동작합니다.

## 출처
학교알리미 정보공시(교육부·한국교육학술정보원), 서울 열린데이터광장, NEIS 교육정보개방포털, 공공데이터포털, 서울특별시교육청 공개 자료. 각 자료의 기준일은 `데이터_출처_기준.md`와 내려받은 CSV·엑셀 파일 맨 아래 출처 줄에 적혀 있습니다.
